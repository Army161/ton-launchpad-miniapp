Privacy Policy

TON Launchpad collects minimal data to operate the Telegram Mini App:

  • Telegram profile — user ID, username, first name (via initData, validated server-side).
  • Wallet address — when you connect via TON Connect (linked to your Telegram ID).
  • On-chain data — token creations and trades are public on TON blockchain.
  • Token images — an image you upload or generate is stored at a public web address, which becomes part of your token's public details. The address does not contain your Telegram user ID; our server log records which Telegram user ID stored which image, so that abuse can be followed up. When you generate an image, the description you type is sent to the AI image provider you pick (through Vercel AI Gateway). Do not put personal information in it.

We do not sell your data. Session tokens expire after 24 hours. Bot token and deploy keys are never stored in the app bundle.
