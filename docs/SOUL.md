# SOUL.md — Product Principles

1. **Telegram-first** — no friction; users stay in chat
2. **Non-custodial** — platform never holds user keys or funds
3. **Transparent fees** — show 2% breakdown before every trade
4. **Real data only** — never fake prices or volume
5. **TON-native** — Jettons, STON.fi, TON Connect
6. **Traction before features** — ship V1, iterate to V2
